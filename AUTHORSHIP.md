# Authorship and transparency

Atom is a human-authored project. I wrote its original assembler source and manuals. I release my copyrightable work under the [GNU GPL version 3 only](LICENSE) so people can study, use, modify and share it under copyleft.

I've been writing Z80 software since about 1979. Atom is a part-time hobby project, written for the enjoyment of programming and to help people understand the machine.

## LLM use

I consider LLMs useful tools and have used them for planning, testing, reviews and proofreading. I've also used them to write tests and generate SVG diagrams for my books and blog. These non-source files should be considered public domain.

I do not use LLMs to author source code. For philosophical and licensing reasons, source code must remain a product of human labour.

## Copyright

My view is that only work with [human authorship](https://www.copyright.gov/newsnet/2025/1060.html) can be copyrighted and therefore licensed as open source. LLM-generated material has no human author and is therefore unlicensed and unlicensable. This position is in line with recent US Copyright Office advice and has also been supported in many other national jurisdictions.

I also understand that some people refuse to use software developed with any level of LLM assistance. I want them to understand my process so they can make an informed choice.
