Atom

Atom is a single-pass Z80 assembler written in Z80. It runs on CP/M or on a desktop through the Debug80 emulator.

CP/M downloads

Version 0.3.7. The Triptych disk includes ATOM.COM, EDIT.COM and a HELLO.ASM example with its assembled HELLO.COM.

  • Download ATOM.COM
  • Run Atom in Triptych
  • Download the 2 MiB disk image
  • Triptych disk recipe
  • Download checksums

On CP/M, ATOM HELLO reads HELLO.ASM and writes HELLO.COM. In Triptych, the assembler and example are on the writable A: drive.

Desktop

The desktop command requires Node.js 20 or later.

npm install --global atom-z80
atom main.asm

This writes build/main.bin. An output filename can select Intel HEX, CP/M COM, a listing or a Debug80 map.
